
# 🍔 Responsive Delivery Website

A modern, highly interactive, and fully responsive delivery service website. Built with a focus on aesthetic design and seamless user experience across all devices. 



## ✨ Key Features

* **📱 Mobile-First Methodology:** Developed primarily for mobile devices first, scaling up flawlessly to tablet and desktop screens.
* **🌓 Dark & Light Mode:** Includes a fully functional theme switcher to enhance visual accessibility and user preference.
* **🗺️ Real-Time Map Location:** Integrated map tracking section for an immersive delivery experience.
* **✨ Scroll Animations:** Beautiful, engaging animations that trigger dynamically as the user scrolls down the page.
* **🖱️ Smooth Scrolling:** Seamless and fluid navigation across different sections of the website.
* **🎨 Modern UI/UX:** A clean, pleasant, and highly intuitive interface designed to provide the best user experience.

## 🛠️ Tech Stack

* **HTML5** - Semantic markup
* **CSS3** - Custom properties, animations, and responsive layouts
* **JavaScript (Vanilla)** - DOM manipulation, theme switching, and scroll events


### Prerequisites

You don't need any complex development environment to run this project—just a modern web browser.
